What are we doing?

  • PromoTrack is a client-side web application that enables employees to build, manage, and export their promotion portfolio in a single unified tool. It replaces the manual process of assembling STAR entries, performance metrics, and narrative sections across disconnected documents and spreadsheets.
  • The app runs in the browser with AES-256-GCM encrypted local storage namespaced per user, authenticated via Midway JWT, and includes AI-assisted coaching via Amazon Bedrock (Claude Haiku 4.5). The AI is an advisor only: it grounds every suggestion in the user's own words (verbatim-quote justification) and never judges promotion readiness.
  • All portfolio data can be exported as encrypted portable files or formatted DOCX/PDF documents ready for submission.
  • Deployed on the Harmony platform at promo-track.harmony.a2z.com (prod) and promo-track.beta.harmony.a2z.com (beta). Backend APIs authenticated via Midway JWT (SAM stacks in eu-west-1).

Stakeholders / Customers:

  • Individual contributors preparing promotion portfolios (primary users)
  • Managers reviewing and approving promotion documents
  • STEAM committee members evaluating promotion readiness
  • IT Support / Engineering teams (initial rollout)

Why are we doing it?

  • Business justification: The current promotion process is fragmented — employees manually compile data from GSD scorecards and blank Word templates, leading to inconsistent quality and missed evidence. Employees spend significant time on formatting rather than content quality.
  • Impact in current state: No single tool tracks promotion readiness or identifies gaps in Role Guideline coverage. Managers lack visibility into portfolio completeness before submission deadlines.
  • Related goals: Reduce portfolio preparation time from days to hours. Improve the quality and completeness of promotion submissions across the organization.

How are we doing it?

Components:

  • Lock Screen — passphrase-based access control with encrypted storage
  • Promotion Readiness — 7 L4 Role Guideline accordion cards, per-guideline icons, segmented progress rail, deterministic scoring, AI auto-suggest with accept/dismiss chips
  • STAR Editor — create/edit entries with Role Guideline tagging; simplified dialog (date auto-set)
  • Guidelines Page — IC Promotion Wiki content synced via npm run sync-wiki, DOMPurify-sanitized
  • Metrics (MetricEvolution) — weekly + monthly LineCharts; layout-resilient V2 PDF parser with diagnostics
  • Documents Hub — export encrypted .portfolio files, DOCX, PDF, HTML
  • Profile — employee info, promotion targets, narrative sections
  • Timeline — chronological view of all portfolio activity
  • AI Coach — grounded suggestions (PROMO_COACH_SYSTEM), quote validation, gap analysis
  • Manager Review — authenticated share-for-review with retry/stash comment import

Technologies:

  • React 19, TypeScript 5.9, Vite 8, MUI 7, Recharts
  • Web Crypto API (AES-256-GCM, PBKDF2) for encryption
  • docx / jsPDF for document generation, DOMPurify for XSS prevention
  • Amazon Bedrock (Claude Haiku 4.5) via Lambda + API Gateway
  • aws-jwt-verify (backend Midway JWT authentication)
  • @amzn/harmony-build-tools for deployment
  • Ollama (local AI fallback) — optional

Data stores:

  • Browser localStorage (AES-256-GCM encrypted, per-alias namespaced) — primary client data
  • DynamoDB: promo-track-users (cloud persistence), promo-track-reviews (sessions with TTL)

External tech dependencies:

  • Harmony Platform (primary static SPA deployment)
  • AWS Lambda + API Gateway (authenticated backend APIs + AI proxy)
  • Midway (JWT authentication via JWKS)
  • IC Promotion Wiki (guidelines sync source via mcurl + Midway)
  • Ollama / Amazon Bedrock (AI features)

Personnel:

  • 1 developer (design + implementation)
  • Manager review for requirements alignment
  • Security review for encryption and data handling

Backfills / modification of existing data:

  • None — greenfield application, no existing systems modified

Summary of design review

  • Architecture: Client-side SPA with encrypted localStorage + authenticated serverless backend (SAM) — zero idle infrastructure cost
  • Security: Midway JWT auth on all APIs (RS256, alias binding), AES-256-GCM encryption at rest, passphrase lock screen, locked CORS, DOMPurify sanitization, AI grounding rules, per-user data isolation — overall risk: LOW
  • Trade-off accepted: Client-primary storage limits cross-device sync but eliminates complexity and data privacy concerns; userdata API provides optional cloud backup
  • AI: Amazon Bedrock (Claude Haiku 4.5) — advisor only, grounded suggestions, quote validation, no outcome predictions. Data stays within AWS (~$0.001/request)
  • Deployment: Harmony platform (primary) + SAM backend (Lambda/API Gateway/DynamoDB) + Amplify (legacy) — fully serverless, pay-per-use
  • Tests: 181 tests (157 frontend + 24 backend) across storage, scoring, PDF parsing, auth, review import (Vitest + Node.js test runner)
